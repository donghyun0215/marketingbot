# 문제 정의 카드

## 한 문장 정의
**우리는 [여덟 단계가 전부 사람 손으로 돌아가고, 판단의 근거가 어디에도 쌓이지 않기] 때문에 발생하는
[콘텐츠 성과의 원인 불명 · 발행 병목 · 매번 처음부터 다시 하는 기획] 문제를 해결한다.**

## 왜 중요한가 — 숫자 (출처: 코드프레소 제공 6개월 실데이터 2026.02.27~08.25 + 출제 브리프)
| 사실 | 수치 | 출처 |
|---|---|---|
| 3명이 돌리는 월 콘텐츠 물량 | 30건+ / 6개 채널 | 브리프 |
| 경영진 컨펌 소요 | 1~4일 · 발행 타이밍 상실 월 수회 | 브리프 |
| 성과 취합 수작업 | 매주 2시간, 취합 후 폐기 | 브리프 |
| 원고 1편 작성 | 반나절~하루 | 브리프 |
| **진성 문의 10건 중 출처 불명** | **6건** (확정 1 · 추정 3) | 실데이터 인바운드_문의 |
| GA4 form_submit ↔ 문의 폼 | **미연동** (회사 스스로 개선 필요로 명기) | 실데이터 주의사항 |
| 노출은 높은데 클릭 0인 콘텐츠 | 노출 610회 · 클릭 0 | 실데이터 GSC |
| 검색 수요는 있는데 놓치는 검색어 | "인재 채용 전략" 노출 221회 · 평균 20.6위 | 실데이터 GSC |

핵심 병목의 재정의: **컨펌이 1~4일 걸리는 이유는 결재가 느려서가 아니라
경영진이 글 전체를 읽어야 하기 때문이다.** 읽을 양을 줄이면 시간은 따라 줄어든다.

## 이번에 풀지 않는 것 (Out of Scope)
- 이미지·썸네일·영상 편집 자동화
- 뉴스레터 · 유튜브 · 언론 PR 채널
- 외부 채널(LinkedIn) 실제 API 발행 — 발행 큐·포맷 설계까지.
  (사유: 조직 페이지 발행은 Community Management API 별도 승인 필요 → 1주 내 불가.
   단, 실데이터 출처가 해당 API이므로 코드프레소는 이미 권한 보유 = 전환 시 즉시 연결)
- AI 답변 인용(GEO) 측정 — 코드프레소 AEO/GEO 문서의 방향이나 외부 데이터 소스 필요

## 성공의 정의
| 지표 | 현재 | 목표 | 검증 방법 |
|---|---|---|---|
| 초안 1편 | 반나절~하루 | 수 분 | 실측 (생성 로그) |
| 컨펌 | 1~4일 · 글 전체 읽기 | 분 단위 · **확인 지점만** (실측: 정상 글 평균 1곳) | Fact-Guard 로그 |
| 성과 취합 | 주 2시간 | 0분 (자동 브리핑) | 텔레그램 브리핑 |
| **콘텐츠발 문의 귀속** | 추정 포함 40% | **추적 링크 경유분 100%** | inquiries.content_id |
| 톤 일관성 | 개인 역량 의존 | 5축 검사 통과 + 임계 70 (실측 p10) | Voice Score 로그 |

※ 귀속 지표의 정확한 주장: "모든 문의가 귀속된다"가 아니라
**"콘텐츠가 만든 문의를 처음으로 귀속 가능하게 만든다"**. 직접 유입 문의는 여전히 미상으로 남는다.
